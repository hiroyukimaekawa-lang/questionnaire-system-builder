# User Guide (営業担当者・管理者向け)

日々の操作ガイドです。用語の正確な定義は `FEATURE_GLOSSARY.md` を参照してください。
このガイドは実装済みの挙動のみを記載しています。

## ログイン

`/login` にメールアドレスとパスワードでログインします。

## 案件を確認する

ホーム(`/admin`)または`/admin/manage`で担当案件の一覧・状態を確認できます。
「公開中」「作成途中」でフィルタできます。

## 新しいアンケートを作る

1. 「＋ 新しい案件を作成」から `/admin/surveys/new` を開く
2. STEP1 基本情報: 店舗・医院名、業種、タイトル、回答方法(匿名/記名)を設定
3. STEP2 質問作成: 質問を追加・編集・並び替え
4. STEP3 Google口コミ設定: 口コミ導線と条件を設定
5. STEP4 デザイン設定: 色・ロゴなど
6. STEP5 プレビュー・公開: 内容を確認して作成

作成しただけでは公開されません(下書き状態)。

## 既存アンケートを編集する

`/admin/surveys/[id]` の各セクションを編集し、「下書き保存」を押します。
**下書き保存だけでは公開画面は変わりません。**

### 回答方法を変える

「文章・ロゴ設定」の「回答方法」で以下を選べます。

- 回答者が匿名・記名を選択
- 匿名のみ
- 記名のみ

古いアンケート(回答方法が未設定)を開くと「現在の設定を維持(従来形式)」と表示されます。
これを選んでいる間は、明示的にいずれかのモードを選ぶまで、これまでの表示のまま変わりません。

## プレビューで確認する

編集画面のプレビューは公開画面と同じ表示です。ここから送信はできません。

## 公開する

「公開設定」の「公開する」を押すと、今の下書きが公開版になります。
公開後は新しい下書きが自動的に作られるので、続けて編集できます。

## 非公開にする

案件の「非公開にする」操作で、公開URLへのアクセスを止められます。回答データは消えません。

## Google口コミ設定

- 「口コミ・完了条件」で口コミCTAを 使用しない / 全回答者へ表示 / 評価条件を満たした人だけ表示 から選択
- 条件付きの場合は評価質問ごとの基準点と、AND(すべて満たす)/ OR(どれか1つ) を設定
- 「口コミ用文章として使用する質問」で、口コミ画面へ案内する際にコピーする自由記述を選択(「使用しない」を選ぶと口コミ案内は出るがコピーは行わない)

## 回答を確認する

案件の「回答」画面で回答一覧・合計スコア・平均スコアを確認し、CSVをダウンロードできます。

## アンケートを削除する(管理者のみ)

一覧からの削除はアーカイブ扱いで、回答データは保持されます。復元も管理者のみ可能です。

## アンケートAI(社員向けチャット)

有効化されている環境では、管理画面右下の「AIに質問」から操作方法を質問したり、
不具合報告・改善要望をまとめて送ったりできます。詳細は `INTERNAL_ASSISTANT.md` を参照してください。
